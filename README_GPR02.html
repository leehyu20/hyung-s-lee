GPR-02 Quarto website update

This package is a small overlay for your existing HL_Blog folder, not a replacement for your site.

Files to copy

  • posts/gpr-heterogeneous-pavement/index.qmd: full GPR-02 article from the finalized Word draft.
  • posts/gpr-heterogeneous-pavement/media/gpr02-figure-1.png through gpr02-figure-7.png: all seven figures extracted from Word.
  • _quarto.yml: your existing site configuration with one additional resource glob for GPR-02 MP4s.
  • research/gpr.qmd: your existing GPR research page with a new GPR-02 article link.

The original GPR-01, TSD-01, other pages and existing URLs are not changed.

Final MP4 videos needed

The uploaded ZIP does not include the seven final GPR-02 animations. The article therefore uses visible “video pending” notices rather than broken video embeds. Copy these exact files into posts/gpr-heterogeneous-pavement/media/:

  1. crack-pavement-cross-section.mp4
  2. crack-pavement-raw-bscan.mp4
  3. crack-pavement-final.mp4
  4. compaction-pavement-cross-section.mp4
  5. compaction-original-bscan.mp4
  6. compaction-final.mp4
  7. water-table-final.mp4

For each video, edit index.qmd: replace the adjacent ::: {.callout-note ...} block with the shortcode already provided in the nearby HTML comment. Remove the comment block afterward. Captions are already in place.

How to install

  1. Back up or commit your existing HL_Blog working directory.
  2. Copy this package’s contents over your HL_Blog folder, retaining the same relative paths.
  3. Add the seven MP4 files and activate the video shortcodes as described above.
  4. From your HL_Blog directory run quarto render and inspect the local HTML page posts/gpr-heterogeneous-pavement/index.html in _site.
  5. When satisfied, run quarto publish gh-pages, then commit and push your source changes to main as in your established workflow.

The article path will be https://leehyu20.github.io/hyung-s-lee/posts/gpr-heterogeneous-pavement/ once published.

Notes

  • All external hyperlinks embedded in the Word document, including the GPR-01 and LinkedIn references, are retained.
  • Equations (1)–(3) use display LaTeX with their original numbers.
  • Table 1 and all seven figures are included.
  • The article date is set to October 12, 2026; change it in the YAML front matter if publishing on a later date.
  • The homepage still features GPR-01, as before; the Articles listing will discover GPR-02 automatically and the GPR research page links to it.
